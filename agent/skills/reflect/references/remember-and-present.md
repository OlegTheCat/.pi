# Remember and present

Save accepted memory findings and present everything else.

## 1. Save memories

For each accepted memory finding, write it with the available memory tools. Use the scope from synthesis: global, or tied to a specific project. Update or replace an existing entry instead of adding a near-duplicate.

Save only Accepted items. Don't save rejected or needs-verification findings. If no memory tools are available, list the findings under proposals instead.

## 2. Present

Show the user, briefly:

- **Saved to memory:** one line each, with where it was saved, so the user can remove anything they disagree with.
- **Proposed changes:** skill edits, new skills, and tooling fixes. For each, give the problem, the evidence, and the exact change and target. Number them so the user can approve them one by one.
- **Rejected and needs verification:** one line each.
- The reflection file path.

If nothing was accepted, say so plainly.

Mark this stage done and move to stage 6.
